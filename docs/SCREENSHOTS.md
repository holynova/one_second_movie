主界面特点：

## Quality Presets / 质量预设

### Low Quality (32×32 Grid)
- **1,024 screenshots**
- Best for quick previews
- Faster processing time
- Larger individual frames (120×67 px)

### 低质量（32×32 网格）
- **1,024 张截图**
- 适合快速预览
- 处理时间更快
- 单个帧更大（120×67 像素）

---

### Medium Quality (64×64 Grid) - Recommended
- **4,096 screenshots**
- Balanced detail and processing time
- Good for most use cases
- Medium frame size (60×33 px)

### 中质量（64×64 网格）- 推荐
- **4,096 张截图**
- 平衡细节和处理时间
- 适合大多数使用场景
- 中等帧尺寸（60×33 像素）

---

### High Quality (128×128 Grid)
- **16,384 screenshots**
- Maximum coverage
- Longer processing time
- Smaller frames (30×16 px)

### 高质量（128×128 网格）
- **16,384 张截图**
- 最大覆盖率
- 处理时间较长
- 较小的帧（30×16 像素）

## Features Showcase / 功能展示

### Video Information Display
After uploading, the app displays:
- Video duration (formatted as H:MM:SS)
- File size (in MB/GB)

### 视频信息显示
上传后，应用显示：
- 视频时长（格式为 H:MM:SS）
- 文件大小（以 MB/GB 为单位）

### Output Statistics
After processing, view detailed statistics:
- Total number of screenshots
- Grid dimensions (rows × columns)
- Capture interval
- Output resolution (3840×2160)

### 输出统计
处理后，查看详细统计：
- 截图总数
- 网格尺寸（行×列）
- 截图间隔
- 输出分辨率（3840×2160）

### Progress Tracking
Real-time progress bar shows:
- Current percentage
- Processing status
- Estimated time

### 进度追踪
实时进度条显示：
- 当前百分比
- 处理状态
- 预估时间
